Исправленная версия: прокрутка в Tilda и кнопка формы.

Что исправлено:
1. Убран внутренний скроллбар iframe, из-за которого страница «крутилась» неправильно.
2. Добавлена автоматическая высота iframe через postMessage: Tilda подстраивает высоту блока под сайт.
3. Кнопка «Отправить заявку» теперь вызывает форму Tilda через popup.
4. Код остался без папки assets: все фотографии лежат рядом с index.html.

Как загрузить:
1. Загрузи все файлы из этой папки в одно место на хостинге: index.html и все .jpg.
2. Получи публичную ссылку на index.html.
3. В Tilda вставь НОВЫЙ код из tilda_iframe_code.txt в блок T123 / HTML.
4. Замени URL_NA_VASH_INDEX_HTML на публичную ссылку.
5. Опубликуй страницу Tilda.

Важно:
Чтобы кнопка открывала форму, в Tilda должен существовать popup с ссылкой #popup:toursbf502n.
Если в Tilda указан вариант со space (#popup:tours bf502n), код также пробует открыть его, но лучше переименовать popup без пробела.
