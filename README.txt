Обновленная версия страницы «Снежная открытка».

Что изменено:
1. Добавлено больше продающего текста по документам: история фестиваля, международный масштаб, участие компаний, ледовый парк и партнерские форматы.
2. В «Медиа фестиваля» добавлены новые фотографии. Первой стоит файл g4y_mKy... из ваших вложений.
3. Исправлен автоскролл: при открытии сайта страница остается наверху, а не прыгает к блоку «Медиа фестиваля».
4. Кнопки заявки ведут на popup Tilda: #popup:tours.
5. Структура без папки assets: index.html и все изображения лежат в одной папке.
6. Внутренняя прокрутка iframe отключена, высота передается автоматически в родительский Tilda-блок.

Как загрузить:
1. Распакуйте архив.
2. Загрузите все файлы из папки в одно место на хостинге: index.html, фотографии, tilda_iframe_code.txt.
3. Получите публичную ссылку на index.html.
4. В Tilda замените старый код iframe на код из tilda_iframe_code.txt.
5. В коде замените URL_NA_VASH_INDEX_HTML на публичную ссылку на index.html.
6. Проверьте, что на странице Tilda есть popup с адресом #popup:tours.
